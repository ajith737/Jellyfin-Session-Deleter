Add a configurable option called "Max Sessions Per User" (integer, default: 5).
When the scheduled task runs, for each user in Jellyfin:
Retrieve all stored devices for that user via IDeviceManager.GetDevices() (not just active sessions — this covers all registered devices, including ones not currently streaming).
Count the number of devices for that user.
If the count exceeds the configured max, sort the devices by DateLastActivity ascending (least recently used first — e.g., a device last used 3 days ago is deleted before one last used 2 days ago).
Delete the excess devices (oldest LastActivityDate first) using IDeviceManager.DeleteDevice(deviceId) until the count is at or below the limit.
Sorting logic (critical):

Sort devices by DateLastActivity ascending (oldest last-used date first).
Example: Device A last used 3 days ago, Device B last used 2 days ago → delete Device A first.
This is the opposite of SessionManager.Sessions which orders by LastActivityDate descending.
